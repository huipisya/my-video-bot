# Luno Bot — Advanced Video Downloader Bot (`my-video-bot`)

Telegram-бот для загрузки видео и аудиоматериалов из популярных социальных сетей и платформ (YouTube, Instagram, TikTok, Twitter/X, Facebook и других). 

Бот снабжен механизмами обхода блокировок парсинга (включая автоматическое получение YouTube PO Token и ротацию куки Instagram через Playwright) и полностью готов к деплою в Docker / Heroku / Railway.

---

## 🔥 Ключевые особенности

### 1. 🌐 Мультиплатформенность
* Поддержка скачивания медиафайлов с большинства популярных видеоплатформ благодаря интеграции с `yt-dlp` и специализированными парсерами.

### 2. 🛡️ Умный обход анти-бот систем (Bypass)
* **YouTube Proof of Origin**: Автоматический запуск headless-браузера **Playwright** для регулярного обновления `poToken` и `visitorData`, перехватывая сетевые запросы YouTube API.
* **Instagram Cookie Rotation**: Ротация и автоматическое обновление cookies для нескольких аккаунтов-ботов (`cookies_instagram_bot1.txt` и т.д.) каждые 30 минут с авторизацией через Playwright, минимизируя риск банов.

### 3. ⚙️ Гибкие настройки качества
* Выбор желаемого разрешения видео перед загрузкой (Best, 1080p, 720p, 480p) или скачивание только звуковой дорожки (аудио в MP3/M4A).

### 4. 💎 Лимиты и Реферальная система
* Ограничение дневного количества загрузок для бесплатных пользователей.
* Премиум-подписка с неограниченным качеством и отсутствием лимитов.
* Реферальная программа — пользователи могут приглашать друзей по ссылке для получения бонусных возможностей.

### 5. 🐳 Контейнеризация и Webhook
* Полный Dockerfile для развертывания бота в изолированном контейнере со всеми необходимыми системными зависимостями (включая браузер Chromium для Playwright).
* Поддержка работы как через Webhook (`aiohttp`), так и через Polling.

---

## 🛠️ Технологический стек

* **Язык**: Python 3.10+
* **Фреймворк**: `aiogram` (версия 3.x)
* **Инструмент загрузки**: `yt-dlp` (с обходом IP/Client ограничений) + `pytubefix`
* **Браузерная автоматизация**: `playwright` (Chromium)
* **HTTP клиент/сервер**: `aiohttp`
* **Сетевой клиент**: `curl-cffi` (для маскировки TLS-отпечатков под Chrome)
* **Управление переменными**: `python-dotenv`

## ⚙️ Настройка и Деплоймент

### 1. Переменные окружения (.env)
Создайте файл `.env` на основе следующих переменных:

```env
BOT_TOKEN=your_telegram_bot_token
BOT_USERNAME=your_bot_username

# Настройки Webhook (необязательно, для Polling оставьте пустым)
WEBHOOK_HOST=https://your-domain.com
PORT=8000

# Cookies для обхода ограничений (вставьте JSON-строку экспортированных куки)
COOKIES_YOUTUBE=[{"name": "...", "value": "..."}]
COOKIES_BOT1=[{"name": "...", "value": "..."}]
COOKIES_BOT2=[{"name": "...", "value": "..."}]
```

### 2. Запуск через Docker (Рекомендуется)
Использование Docker гарантирует установку всех зависимостей Playwright (браузера Chromium и библиотек):

```bash
# Сборка образа
docker build -t luno-video-bot .

# Запуск контейнера
docker run -d --name video-bot --env-file .env luno-video-bot
```

### 3. Ручной запуск (Локально)
```bash
# Установка Python пакетов
pip install -r requirements.txt

# Установка браузеров Playwright
playwright install chromium

# Запуск бота
python bot.py
```
